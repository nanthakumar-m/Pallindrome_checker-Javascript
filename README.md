# 🔁 Palindrome Checker – JavaScript

The Palindrome Checker is a simple web tool that lets users input a word and check whether it's a palindrome—a word that reads the same forwards and backwards. It provides instant visual feedback upon checking.

This project was created to practice fundamental JavaScript string manipulation, DOM updates, and user input handling in real-time. It served as a fun and effective way to apply conditional logic and string methods like .split(), .reverse(), and .join().

🔗👉click here to see the live demo-->https://nanthakumar-m.github.io/Pallindrome_checker-Javascript/

## ⚙️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💡Core Features

✅ Checks if a given input is a palindrome

✅ Realtime result display with positive or negative feedback

✅ Input validation with alert for empty input

✅ DOM manipulation to dynamically display messages

✅ Simple and responsive layout with CSS styling

✅ Strengthened conditional checking in JavaScript

✅ Learned to dynamically create and update DOM elements
